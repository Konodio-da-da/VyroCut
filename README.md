# VyroCut

A native, fully offline Android video editor targeting Android 10 (API 29) and above. Editing, rendering, project storage, and AI-assisted features are designed to run on-device.

## Foundation
- Kotlin and Jetpack Compose
- Gradle Kotlin DSL
- Media3 / Transformer editing pipeline
- Room for local project metadata
- No cloud dependency

Open the project in Android Studio with a compatible Android SDK installed. Features will be implemented incrementally and verified on-device; mock UI is not considered a completed editing feature.
